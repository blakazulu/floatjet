## Affiliate Programs Overview

### Revenue Model

**Focus:** Prioritize programs with:

1. ✅ **Recurring commissions** (passive income)
2. ✅ **High ticket** ($50+ per sale)
3. ✅ **Long cookies** (30+ days)
4. ✅ **Relevant to niche** (remote work, productivity)

**Avoid:**

- ❌ Low commission (<$10)
- ❌ Short cookies (<7 days)
- ❌ Unreliable tracking
- ❌ Poor reputation/quality products

### Goals

- **Month 1:** Join 5 core programs (Tier 1)
- **Month 2:** Add 5 more programs (Tier 2)
- **Month 3:** Diversify with Tier 3 programs
- **Target:** 10-15 active programs by Month 3

## Link Management

### URL Structure

**Short Link Format:**

```
https://floatjet.com/go/[program-name]
```

**Examples:**

- `https://floatjet.com/go/notion`
- `https://floatjet.com/go/clickup`
- `https://floatjet.com/go/nordvpn`
- `https://floatjet.com/go/convertkit`

### Implementation Options

**Option 1: Netlify Redirects** (Recommended)

```toml
# netlify.toml
[[redirects]]
from = "/go/notion"
to = "https://affiliate.notion.so?ref=floatjet&utm_source=floatjet&utm_medium=affiliate"
status = 301
force = true

[[redirects]]
from = "/go/clickup"
to = "https://clickup.com/?fp_ref=floatjet"
status = 301
force = true
```

**Option 2: Netlify Functions** (For tracking)

```javascript
// netlify/functions/affiliate-redirect.js
export async function handler(event) {
  const program = event.path.split('/go/')[1];

  // Track click in PostHog
  await trackClick(program);

  // Redirect to affiliate URL
  const url = getAffiliateUrl(program);
  return {
    statusCode: 301,
    headers: {Location: url}
  };
}
```

**Decision:** Start with Option 1 (simpler), add Option 2 later if we need advanced tracking.

### UTM Parameters

**Standard Format:**

```
?utm_source=floatjet&utm_medium=affiliate&utm_campaign=[article-slug]
```

**Example:**

```
https://notion.com?ref=floatjet&utm_source=floatjet&utm_medium=affiliate&utm_campaign=best-project-management
```

- Track which articles drive conversions

## Commission Tracking Process

### Weekly Tasks (Monday)

- [ ] Log into each affiliate dashboard
- [ ] Check pending commissions
- [ ] Note any new sales
- [ ] Screenshot dashboards (for records)
- [ ] Update Google Sheet tracker

### Monthly Reconciliation (1st of month)

- [ ] Log into all affiliate dashboards
- [ ] Export commission reports (previous month)
- [ ] Update master tracking spreadsheet
- [ ] Calculate total earnings
- [ ] Note top-performing programs
- [ ] Note top-performing articles (via PostHog)
- [ ] Identify underperforming programs (consider dropping)

### Quarterly Review (Every 3 months)

- [ ] Analyze revenue by program
- [ ] Analyze revenue by article
- [ ] Identify winning combinations
- [ ] Drop programs making <$50/quarter
- [ ] Add new programs based on content performance
- [ ] Update affiliate link placements based on data

## Notes & Reminders

### Best Practices

✅ **Do:**

- Only recommend products you'd actually use
- Be honest about pros AND cons
- Disclose affiliate relationships clearly
- Track performance and optimize
- Update affiliate links when better programs emerge
- Test all affiliate links regularly

❌ **Don't:**

- Recommend bad products for high commissions
- Hide affiliate disclosures
- Use excessive affiliate links (looks spammy)
- Rely on single program for >40% revenue
- Ignore underperforming programs
- Forget to track and optimize

### Common Pitfalls

1. **Cookie expiration** - Promote with urgency
2. **Broken links** - Check monthly
3. **Program changes** - Monitor for commission cuts
4. **Attribution issues** - Use clear tracking
5. **Compliance** - Always disclose, follow FTC guidelines
