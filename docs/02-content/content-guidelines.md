## Writing Tone & Voice

### Brand Personality

**FloatJet is:**

- 🎯 **Helpful** not salesy
- 💡 **Knowledgeable** not condescending
- 📊 **Data-driven** not purely opinion-based
- 🤝 **Honest** not biased by commissions
- ⚡ **Practical** not theoretical

**FloatJet is NOT:**

- ❌ Corporate or overly formal
- ❌ Hype-driven or clickbait-y
- ❌ Pushy with affiliate links
- ❌ Vague or fluffy
- ❌ Biased toward highest-paying affiliates

### Voice Guidelines

**Perspective:**

- Use "we" when speaking as FloatJet
- Use "you" when addressing the reader
- Avoid "I" unless sharing personal experience

**Examples:**

- ✅ "We tested 15 VPNs to find the best options for remote workers"
- ✅ "You'll save hours each week with the right project management tool"
- ❌ "I think Notion is pretty cool"

**Tone:**

- Professional but approachable
- Confident but not arrogant
- Enthusiastic but not over-the-top
- Helpful but not patronizing

**Writing Style:**

- Active voice: "We tested 20 tools" not "20 tools were tested"
- Short sentences: 15-20 words average
- Short paragraphs: 2-4 sentences
- Scannable: Use headings, bullets, tables
- Clear: Avoid jargon (or explain it)

**Language:**

- US English spelling
- Contractions are fine (it's, you'll, we've)
- Second person ("you") for engagement
- Present tense when possible

## SEO Pre-Publish Checklist

### Before Publishing ANY Article

**Content SEO:**

- [ ] Target keyword in H1 (article title)
- [ ] Target keyword in URL slug
- [ ] Target keyword in first paragraph (first 100 words)
- [ ] Target keyword density: 1-2% (natural, not stuffed)
- [ ] LSI keywords throughout (related terms)
- [ ] Heading hierarchy (H1 → H2 → H3, logical structure)
- [ ] No orphan headings (content under each heading)

**Meta Data:**

- [ ] Meta title: 50-60 characters, includes keyword
- [ ] Meta description: 150-155 characters, includes keyword + CTA
- [ ] URL slug: lowercase, hyphens, keywords, short
- [ ] Canonical URL: set to self

**Images:**

- [ ] Featured image: 1200x630px (Open Graph)
- [ ] All images have descriptive file names
- [ ] All images have alt text (descriptive, keyword when relevant)
- [ ] Images optimized (WebP format, <200KB each)
- [ ] Lazy loading enabled (below fold)

**Links:**

- [ ] 5-10 internal links to related articles
- [ ] 2-3 external links to authoritative sources
- [ ] All affiliate links have `rel="nofollow sponsored"`
- [ ] All external links have `target="_blank" rel="noopener"`
- [ ] No broken links (check before publishing)

**Schema Markup:**

- [ ] Article schema (every article)
- [ ] Review schema (if product review)
- [ ] FAQ schema (if FAQs included)
- [ ] HowTo schema (if tutorial)
- [ ] BreadcrumbList schema
- [ ] Schema validated (Google Rich Results Test)

**Affiliate Compliance:**

- [ ] Affiliate disclosure at top of article
- [ ] Disclosure clear and conspicuous
- [ ] FTC compliant wording

**Mobile Optimization:**

- [ ] Preview on mobile (375px width minimum)
- [ ] Readable font sizes (16px minimum)
- [ ] Touch-friendly buttons (48x48px minimum)
- [ ] No horizontal scroll
- [ ] Fast loading on mobile (test with Lighthouse)

**Performance:**

- [ ] Lighthouse Performance: 90+ (mobile and desktop)
- [ ] Core Web Vitals passing
- [ ] Images compressed
- [ ] No render-blocking resources

**Final Checks:**

- [ ] Spell check (Grammarly)
- [ ] Fact check (all claims accurate)
- [ ] Dates current (if time-sensitive)
- [ ] Affiliate links working
- [ ] Preview in staging
- [ ] Mobile preview

## Image Guidelines

### Image Types & Specs

**Featured Image (Required):**

- Dimensions: 1200x630px (Open Graph standard)
- Format: WebP with JPEG fallback
- Max file size: 200KB
- Alt text: Descriptive, includes keyword
- Location: `/public/images/[slug]/featured.webp`

**In-Content Images:**

- Screenshots: 1200px wide (retina quality)
- Diagrams: SVG when possible (scalable, small)
- Icons: 48x48px to 128x128px
- Format: WebP preferred
- Max file size: 100-150KB each

**Product Logos (for comparison tables):**

- Size: 120x120px
- Format: PNG with transparency or WebP
- Max file size: 20KB
- Alt text: "[Company Name] logo"

### Optimization Process

1. **Resize** to appropriate dimensions
2. **Compress** with TinyPNG or Squoosh
3. **Convert** to WebP (with JPEG/PNG fallback)
4. **Name descriptively**: `best-project-management-software-comparison.webp`
5. **Add alt text**: "Comparison table showing Notion, ClickUp, and Monday.com features"

### Alt Text Best Practices

**Good Alt Text:**

- ✅ Descriptive: What's in the image
- ✅ Concise: 10-15 words
- ✅ Keyword when relevant (naturally)
- ✅ Unique for each image

**Examples:**

- ✅ "Notion dashboard showing project management kanban board"
- ✅ "NordVPN speed test results showing 450 Mbps"
- ❌ "Image"
- ❌ "Screenshot"
- ❌ "Notion Notion Notion project management Notion" (keyword stuffing)

### Responsive Images

Always use `srcset` for responsive images:

```html
<img
  src="image-800w.webp"
  srcset="
    image-400w.webp 400w,
    image-800w.webp 800w,
    image-1200w.webp 1200w"
  sizes="
    (max-width: 640px) 100vw,
    (max-width: 1024px) 80vw,
    1200px"
  alt="Descriptive alt text"
  loading="lazy"
/>
```

## Internal Linking Strategy

### Goals

1. **SEO:** Pass authority to important pages
2. **UX:** Help readers find related content
3. **Conversions:** Guide readers to money pages
4. **Crawlability:** Help Google discover all pages

### Link Targets Per Article

- **Minimum:** 5 internal links
- **Target:** 7-10 internal links
- **Maximum:** 15 internal links (don't overdo it)

### Where to Link

**From New Articles:**

- ✅ Link to older, related articles
- ✅ Link to category pages
- ✅ Link to main money pages
- ✅ Link to comprehensive guides

**From Old Articles:**

- Go back and add links to new content
- Update at least quarterly

### Link Placement

**Best locations:**

1. **Contextual** (within paragraphs)
2. **Related articles** (end of post)
3. **Calls-out** (boxes, highlights)

**Avoid:**

- ❌ Long lists of links (looks spammy)
- ❌ All links in footer/sidebar only
- ❌ Irrelevant links just to hit quota

### Anchor Text Best Practices

**Good Anchor Text:**

- ✅ Descriptive: "best project management software"
- ✅ Natural: "we also tested VPNs for digital nomads"
- ✅ Varied: Don't use same anchor text repeatedly

**Bad Anchor Text:**

- ❌ "Click here"
- ❌ "Read more"
- ❌ "Link"
- ❌ Exact match keyword 20 times

**Examples:**

```markdown
If you're looking for the [best VPN for remote work](/tools/best-vpn-remote-work),
we've tested over 15 options.

Check out our guide on [setting up a home office on a budget](/guides/home-office-budget)
for more tips.
```

### Internal Linking Hierarchy

**Priority 1:** Money pages

- These convert → link from supporting content

**Priority 2:** Category pages

- These organize → link from articles

**Priority 3:** Supporting content

- These educate → link from money pages

**Priority 4:** SEO traffic builders

- These attract → link to money pages

## Mobile-First Writing

### Why It Matters

- 60%+ of traffic is mobile
- Google uses mobile-first indexing
- Mobile readers scan, don't read
- Smaller screens = need brevity

### Mobile-First Writing Principles

**1. Shorter Everything**

- Sentences: 15-20 words max
- Paragraphs: 2-4 sentences max
- Sections: 300-400 words max before next heading

**2. More Headings**

- H2 every 300-400 words
- H3 for sub-topics
- Helps mobile scanning

**3. Bullet Points & Lists**

- Easier to scan on mobile
- Better than long paragraphs
- Use liberally

**4. Tables for Data**

- Better than paragraphs of specs
- Make responsive (scroll on mobile)
- Keep columns to 3-4 max

**5. Clear CTAs**

- Touch-friendly buttons (48x48px)
- Above the fold on mobile
- Clear next action

**6. Avoid Long Sentences**

```
❌ "While there are many project management tools available on the market today,
    and each one has its own unique set of features and pricing tiers that may
    or may not be suitable for your specific use case, we've found that Notion
    tends to work best for most remote teams."

✅ "We tested 15 project management tools. Notion works best for most remote teams.
    Here's why."
```

### Test on Mobile

- Always preview on 375px width (iPhone SE)
- Check readability
- Check button sizes
- Check image scaling

## AI Crawler Optimization

### Why Optimize for AI Search

- ChatGPT Search, Perplexity, Claude are growing
- AI citations drive high-quality traffic
- Early adopters gain advantage
- Complements traditional SEO

### How AI Crawlers Work

1. **Crawl** the web like Google
2. **Parse** content structure
3. **Extract** key information
4. **Cite** in AI responses

### Optimization Techniques

**1. Clean, Semantic HTML**

```html
<article>
  <header>
    <h1>Article Title</h1>
    <time datetime="2025-12-01">December 1, 2025</time>
  </header>

  <section>
    <h2>Section Title</h2>
    <p>Content...</p>
  </section>
</article>
```

**2. Structured Data (Schema.org)**

- Article schema on every post
- FAQ schema for question sections
- Review schema for product reviews
- HowTo schema for tutorials

**3. Clear Heading Hierarchy**

- H1: Main title (one per page)
- H2: Main sections
- H3: Sub-sections
- Never skip levels (H2 → H4)

**4. Factual, Data-Driven Content**

- AI prefers objective facts
- Include statistics, data, numbers
- Cite sources
- Avoid pure opinion

**5. FAQ Sections**

- AI often pulls from FAQs
- Answer common questions
- Use question format in headings

**6. Fast Loading**

- AI crawlers have budgets
- Slow sites get crawled less
- Aim for <2s load time

**7. Updated Dates**

- AI prefers recent content
- Update publish dates quarterly
- Mark as "Updated: [Date]"

### What AI Crawlers Look For

✅ **Good for AI:**

- Clear structure (headings, lists)
- Factual information
- Data and statistics
- Step-by-step instructions
- FAQ sections
- Updated dates
- Fast loading

❌ **Bad for AI:**

- Walls of text
- No structure
- Pure opinion
- Outdated information
- Slow loading
- JavaScript-heavy (Astro fixes this)

## Frequently Asked Questions

### What is the best free project management software?

**Notion** is the best free option for small teams (up to 10 people). You get unlimited pages, databases, and blocks. **Asana** is also excellent for up to 15 users with basic project management features.

For freelancers working solo, **Todoist** or **Trello** work well and stay free forever.

### Can project management software replace email?

Not entirely, but it can significantly reduce email volume. Tools like Notion, ClickUp, and Asana include comments, @mentions, and notifications that replace many status update emails.

We've found that teams using project management software reduce internal email by 50-70%.

### Which project management software works best for remote teams?

**Notion** is our top pick for remote teams because it's designed for async work. Everything is documented, searchable, and accessible from anywhere.

**ClickUp** and **Monday.com** also work well, especially for teams that need more advanced project tracking features.

### Do I need project management software if I have Slack?

Yes. Slack is great for communication but terrible for project tracking. Conversations get lost, tasks fall through the cracks, and there's no single source of truth.

Project management software keeps everything organized, trackable, and searchable. Use Slack for quick chats, use project software for actual work.

### How much does project management software cost?

Most tools cost **$7-15 per user per month** for standard plans. Many offer free tiers for small teams:
- **Notion:** Free up to 10 users, then $8/user
- **ClickUp:** Free up to 5 users, then $7/user
- **Asana:** Free up to 15 users, then $10.99/user
- **Monday.com:** No free tier, starts at $8/user
