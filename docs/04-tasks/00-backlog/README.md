# Task Backlog

This folder contains future ideas, enhancement requests, and tasks that haven't been prioritized yet.

---

## What Goes in the Backlog?

- Future content ideas
- Feature enhancement requests
- Optimization opportunities
- Technical debt to address later
- "Nice to have" improvements

---

## How to Use the Backlog

1. **Add ideas** to the appropriate backlog file
2. **Don't create task files yet** - just capture the idea
3. **Review monthly** - promote items to active tasks when ready
4. **Keep it organized** - use the category files below

---

## Backlog Files

- `content-ideas.md` - Future article topics
- `feature-requests.md` - Site features and enhancements
- `optimization-ideas.md` - Performance and UX improvements

---

## When to Move to Active Tasks

Move a backlog item to active tasks when:

- It becomes high priority
- You have time to work on it
- It supports a current goal
- Dependencies are resolved
