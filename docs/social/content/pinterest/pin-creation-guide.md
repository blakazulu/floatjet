# Pinterest Pin Creation Guide

Step-by-step guide for creating FloatJet pins. Follow this for every pin.

---

## Quick Reference

| Spec          | Value                       |
| ------------- | --------------------------- |
| Standard Size | 1000 x 1500 px (2:3)        |
| File Format   | PNG or JPG                  |
| Max File Size | 20MB (aim for <5MB)         |
| Min Font Size | 24pt                        |
| Description   | 150-300 characters          |
| Hashtags      | None (use keywords instead) |

---

## Step 1: Choose Your Article

Pick an article to create pins for. Each article should get 2-3 pin variations.

**Pin angles for the same article:**

| Variation | Focus         | Example                              |
| --------- | ------------- | ------------------------------------ |
| Main      | Primary topic | "7 Best VPNs for Remote Work"        |
| Benefit   | Key takeaway  | "How to Stay Secure on Public WiFi"  |
| List      | Numbers hook  | "5 VPN Features Remote Workers Need" |

---

## Step 2: Create Pin in Canva

### Open Canva

1. Go to canva.com
2. Click "Create a design"
3. Search "Pinterest Pin" or use custom size: **1000 x 1500 px**

### Use FloatJet Brand Colors

| Color      | Hex     | Use For                  |
| ---------- | ------- | ------------------------ |
| Ocean Deep | #0F4C5C | Headlines, backgrounds   |
| Jet Stream | #38A3A5 | Accents, highlights      |
| Sky Light  | #80CED7 | Secondary elements       |
| Sand       | #E0FBFC | Light backgrounds        |
| White      | #FFFFFF | Text on dark backgrounds |

### Pin Layout Structure

---

┌─────────────────────────┐
│  [FloatJet logo - small]│  ← Top corner
│                         │
│     MAIN HEADLINE       │  ← Large, bold text
│     2-3 lines max       │
│                         │
│   [Visual element]      │  ← Screenshot, icon, or image
│                         │
│    Supporting text      │  ← Optional subtitle
│                         │
│   floatjet.com          │  ← URL at bottom
└─────────────────────────┘
---

### Design Checklist

- [ ] Vertical format (2:3 ratio)
- [ ] Large headline (readable on mobile)
- [ ] Max 3 lines of main text
- [ ] FloatJet logo (small, corner)
- [ ] Brand colors used
- [ ] Text not too close to edges (cropping happens)
- [ ] Clean, not cluttered

---

## Step 3: Write Pin Title

The title appears above your pin in search results. Critical for SEO.

### Title Formula

---

[Number] + [Keyword] + [Benefit/Year]
---

**Examples:**

- "7 Best VPNs for Remote Workers (2025)"
- "Home Office Setup Ideas Under $500"
- "5 Productivity Apps That Actually Work"
- "Standing Desk vs Sitting: What's Better?"

### Title Rules

- Front-load keywords (what people search)
- Keep under 100 characters
- Include year for freshness (2025)
- Numbers perform well
- Match the article content

---

## Step 4: Write Pin Description

Descriptions help Pinterest understand and rank your pin.

### Description Template

---

[Hook - what they'll learn]

[1-2 sentences expanding on value]

[Call to action]

[Affiliate disclosure if applicable]
---

### Example Descriptions

**For a VPN review:**

---

Tested 7 VPNs from airports and cafes across 12 countries.

Here's which ones actually work for remote workers—speed tests,
security breakdown, and honest pricing comparison included.

Read the full review →

Contains affiliate links
---

(247 characters)

**For a productivity article:**

---

The productivity apps everyone recommends vs the ones that actually
help you get work done.

I've used all of these for 6+ months. Some are overhyped,
some are hidden gems.

Full comparison inside
---

(218 characters)

**For a home office guide:**

---

Built my home office for under $500. Standing desk, monitor,
chair, lighting—everything you need.

No aesthetic Instagram setup, just what actually makes working
from home comfortable.

Budget breakdown included
---

(229 characters)

### Description Rules

- 150-300 characters optimal
- First 50 characters show in feed (make them count)
- Include 2-4 keywords naturally
- Write like you talk (conversational)
- Add affiliate disclosure when relevant
- **No hashtags** (Pinterest deprecated them in 2025)

### Keywords to Include

Pick 2-4 relevant keywords:

- remote work / remote workers
- productivity / productivity tools
- digital nomad / work from home
- VPN / security / privacy
- home office / office setup / desk setup
- freelance / freelancer
- standing desk / ergonomic
- best [category] 2025

## Step 5: Choose the Right Board

Save each pin to the most relevant board.

### FloatJet Boards

| Board                             | Use For                                     |
| --------------------------------- | ------------------------------------------- |
| Remote Work Tools I Actually Use  | SaaS, productivity apps, project management |
| VPNs for Digital Nomads           | VPN reviews, security content               |
| Home Office Setup Ideas           | Desks, chairs, lighting, workspace          |
| Laptops & Tech Gear               | Hardware, monitors, accessories             |
| Web Hosting for Remote Businesses | Hosting reviews                             |
| Digital Nomad Finance             | Banking, tax, money content                 |
| Travel for Remote Workers         | Destinations, WiFi guides, travel gear      |

### Board Rules

- Save to ONE relevant board only
- Saving to unrelated boards hurts distribution
- Don't save same pin to multiple boards
- Create new board only if you have 5+ pins for that topic

---

## Step 6: Upload & Publish

### In Pinterest

1. Click **Create** → **Create Pin**
2. Upload your image
3. Add destination link (article URL)
4. Add pin title
5. Add pin description
6. Select board
7. Click **Publish** or **Schedule**

### Scheduling Best Times (Israel)

| Day       | Best Time   |
| --------- | ----------- |
| Sunday    | 22:00-01:00 |
| Monday    | 22:00-01:00 |
| Tuesday   | 22:00-01:00 |
| Wednesday | 22:00-01:00 |
| Saturday  | 12:00-15:00 |
| Sunday    | 12:00-15:00 |

Schedule 2-4 weeks ahead for consistency.

## Step 7: Create Variations

Each article needs 2-3 pin designs. Different visuals, different angles.

### Variation Ideas

**Design variations:**

- Different background color
- Different image/screenshot
- Different text layout
- With vs without article image

**Angle variations:**

- Focus on different benefit
- Different headline hook
- Question vs statement
- List vs single tip

### Example: 3 Pins for "Best Standing Desks" Article

| Pin | Headline                                      | Design          |
| --- | --------------------------------------------- | --------------- |
| 1   | "7 Best Standing Desks Under $500"            | Product grid    |
| 2   | "Standing Desk Buying Guide 2025"             | Checklist style |
| 3   | "My Honest Standing Desk Review After 1 Year" | Personal photo  |

## Common Mistakes to Avoid

### Don't

- ❌ Use horizontal images (look tiny)
- ❌ Cram too much text (keep it scannable)
- ❌ Use generic stock photos (low engagement)
- ❌ Forget the destination link
- ❌ Write "Click here!" descriptions
- ❌ Use hashtags (outdated on Pinterest)
- ❌ Save to multiple boards
- ❌ Create one pin per article (make 2-3)

### Do

- ✅ Use vertical 2:3 format
- ✅ Make text readable on mobile
- ✅ Include brand colors and logo
- ✅ Write keyword-rich descriptions
- ✅ Link to the actual article
- ✅ Create multiple variations per article
- ✅ Save to the most relevant board
- ✅ Schedule consistently

## Workflow: Batch Creating Pins

Most efficient way to create pins:

### Weekly Batch Process

1. **Pick 3-5 articles** to create pins for
2. **Open Canva** - create all pin designs in one session
3. **Write all descriptions** in a doc (easy to copy/paste)
4. **Upload to Pinterest** - use native scheduler
5. **Schedule across 2 weeks** (1-3 pins per day)

### Monthly Planning

- Week 1: Create pins for new articles
- Week 2: Create variation pins for top performers
- Week 3: Create seasonal/trending content pins
- Week 4: Review analytics, plan next month

## Analytics: What to Track

Check Pinterest Analytics weekly.

### Key Metrics

| Metric          | What It Means          | Goal             |
| --------------- | ---------------------- | ---------------- |
| Impressions     | How many saw your pin  | Increasing trend |
| Outbound clicks | Clicks to floatjet.com | Most important!  |
| Saves           | Users saved your pin   | Algorithm boost  |
| Pin clicks      | Closeup views          | Interest signal  |

### What to Do With Data

- **High saves, low clicks:** Great design, weak CTA or description
- **Low saves, high clicks:** Good content, design could improve
- **High impressions, low everything:** Wrong audience or weak hook
- **Top pin:** Create more variations of this style
