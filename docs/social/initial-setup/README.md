## Brand Consistency Checklist

Use across ALL platforms:

### Visual Identity

- **Colors:** Ocean Deep (#0F4C5C), Jet Stream (#38A3A5), Sky Light (#80CED7), Sand (#E0FBFC)
- **Fonts:** Outfit (headings), Inter (body)
- **Logo:** Consistent placement and sizing
- **Style:** Glassmorphism with subtle transparency

- **Tagline:** "Tools and gear for remote work success"
