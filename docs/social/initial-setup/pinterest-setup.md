### 5. Enable Rich Pins

**Status:** ✅ READY - Meta tags already configured

**What Are Rich Pins:**

- Automatically pull metadata from your website
- Show article title, description, author
- Update automatically if you change content
- Look more professional and trustworthy
- Get better click-through rates

**Types of Rich Pins:**

- **Article Rich Pins** (best for FloatJet) - blog posts, guides, reviews
- Product Rich Pins - physical products (less relevant)
- Recipe Rich Pins - not relevant

**FloatJet's Meta Tag Status:** ✅ All configured in `src/components/layout/Head.astro`

| Required Tag | Status | Implementation |
|--------------|--------|----------------|
| `og:title` | ✅ | Dynamic from page title |
| `og:description` | ✅ | Dynamic from description |
| `og:image` | ✅ | Auto-generated via astro-opengraph-images |
| `og:type` | ✅ | "article" for articles, "website" for other pages |
| `og:url` | ✅ | Canonical URL |

**How Rich Pins Work Now (2025):**

Pinterest automated the validation process. No manual application needed.

1. Your site already has Open Graph metadata ✅
2. When anyone saves a pin from floatjet.com, Pinterest automatically scans the page
3. If metadata is detected, it becomes a Rich Pin automatically
4. May take up to 24 hours for content to sync

**To Verify It's Working:**

- Create a pin from one of your articles
- Wait 24 hours
- Check if it displays headline/description from your site

**Optional Debugger:** https://developers.pinterest.com/tools/url-debugger/ (may redirect to docs)

**Note:** Rich Pins are critical for affiliate sites - they boost credibility and CTR significantly.

## Pin Design Guidelines

### Pin Dimensions

**Optimal Size:** 1000x1500px (2:3 ratio)

**Why This Size:**

- Pinterest's recommended aspect ratio
- Displays well on mobile (80% of Pinterest traffic)
- Takes up more screen real estate in feed
- 1000px width = high quality, not too large file size

**Alternative Sizes:**

- 1000x1500px (standard, best)
- 1000x2000px (extra tall, more feed space, but can look spammy)
- 735x1102px (minimum acceptable)

**Avoid:**

- Square pins (1:1) - wasted space
- Horizontal pins (look tiny in feed)
- Very tall pins (>1:2.7 ratio) - Pinterest may penalize

### Design Template Requirements

**Essential Elements:**

**1. Eye-Catching Title**

- Large, bold text (readable on mobile)
- 40-60 characters max
- Front-load important words
- Use benefit-driven language

**2. Branding**

- Small FloatJet logo (top or bottom corner)
- Consistent brand colors (Ocean Deep, Jet Stream)
- Don't cover more than 10% of pin

**3. Visual Element**

- Product screenshot or photo
- Infographic chart
- Before/after comparison
- Avoid stock photos (low engagement)

**4. Clear Value Proposition**

- Subtitle or description text
- What they'll learn/get
- Keep text under 20% of pin area (less = better)

**Design Tools:**

**Canva** (Free tier works great)

- Pre-made Pinterest templates
- 1000x1500px custom size
- Brand kit (save FloatJet colors/fonts)
- Batch create 20+ pins quickly

**How to Create Pin Templates in Canva:**

1. Create new design → Custom size → 1000x1500px
2. Add background (solid color or subtle pattern)
3. Add main image/screenshot
4. Add text overlay (title)
5. Add small logo
6. Save as template
7. Duplicate and edit for each pin

**Create 3-5 templates** with different layouts, reuse for all pins.

## Posting Strategy

### Frequency

**Recommended:** 5-10 new pins per week

**Why Not Daily:**

- Quality over quantity on Pinterest
- Algorithm favors consistent, not constant
- Batch creation is more efficient

**Optimal Schedule:**

- **New pins:** 2-3 times per week
- **Repins:** Daily (curate others' content)

### Best Times to Pin (US Audience)

**Peak Times:**

- **Friday 3 PM EST** (highest engagement, weekend planning)
- **Saturday 8-11 PM EST** (weekend browsing)
- **Wednesday 9 PM EST** (mid-week evening)

**Good Times:**

- Tuesday-Friday evenings (8-11 PM EST)
- Weekend mornings (9 AM-12 PM EST)

**Avoid:**

- Monday mornings (work focus)

## Pinterest Rules & Best Practices

### What Pinterest Loves

✅ **High-quality images** (1000x1500px, clear, original)
✅ **Helpful content** (tutorials, guides, tips)
✅ **Consistent pinning** (5-10/week, not 50 one day then silence)
✅ **Fresh content** (new pins, not just repins)
✅ **Verified website** (builds trust)
✅ **Rich Pins** (automatic metadata)
✅ **Niche focus** (don't pin random unrelated stuff)

### What Pinterest Penalizes

❌ **Spam** (too many pins too fast, duplicate pins)
❌ **Clickbait** (misleading titles, false promises)
❌ **Low-quality images** (pixelated, watermarked, text-heavy)
❌ **Affiliate link cloaking** (Pinterest detects and may hide)
❌ **Link stuffing** (too many links in description)
❌ **Unrelated content** (random pins outside your niche)
❌ **Copyright violation** (using others' images without permission)

### Affiliate Link Rules

**Pinterest ALLOWS affiliate links** - no problem there.

**Best Practices:**

- **Disclose** - Add "Affiliate link" or "I earn commissions" in pin description
- **Be honest** - Only pin products you recommend
- **Link directly** - Pinterest prefers direct links (not cloaked redirects)
- **Add value** - Don't just pin product images, create helpful content

**Example Description with Disclosure:**

```
I tested 5 standing desks under $500. This one from [Brand] was the best value - solid build, easy assembly, smooth adjustment.

Full review with measurements and comparisons: [link]

*Affiliate link - I earn a small commission if you purchase, at no extra cost to you.*

#StandingDesk #HomeOffice #RemoteWork
```

## Common Mistakes to Avoid

### Don't:

❌ **Create ugly pins** - Low-quality design = no clicks
❌ **Ignore descriptions** - "Check this out [link]" won't rank
❌ **Pin only your content** - Curate others' relevant pins too

❌ **Neglect board descriptions** - SEO goldmine
❌ **Pin inconsistently** - Algorithm favors steady activity
❌ **Expect instant results** - Pinterest is long game (3-6 months)

### Do:

✅ **Batch create pins** - Design 20 at once in Canva
✅ **Use vertical format** - 2:3 ratio (1000x1500px)
✅ **Write keyword-rich descriptions** - Front-load important words
✅ **Create multiple pins per article** - Different designs, test what works
✅ **Repin others' content** - Builds boards, helps discovery
✅ **Check Pinterest Trends** - Plan seasonal content
✅ **Track analytics weekly** - Double down on what works
